## 📌 Опис проєкту

Репозиторій містить повний комплекс автоматизованих модульних та інтеграційних тестів, розроблених на мові **JavaScript** з використанням тестового фреймворку **Jest**, клієнта **Axios** та системи управління тестуванням **Testomat.io**.

### 1. Базовий навчальний модуль (`unit-integration-tests`):
* **Модульні тести**:
  * `src/math.js` (`tests/math.test.js`) — ізольована перевірка функції додавання чисел `add(a, b)`.
  * `src/auth.js` (`tests/auth.test.js`) — перевірка валідності довжини пароля `isPasswordValid(password)`.
* **Інтеграційні тести**:
  * `src/currency.js` (`tests/currency.test.js`) — внутрішня інтеграція функцій парсингу, форматування та розрахунку валютних сум `addCurrencies`.
  * `src/api.js` (`tests/api.test.js`) — асинхронний запит до віддаленого API `fetchPosts()` з ізоляцією через mock бібліотеки Axios (`jest.mock('axios')`).

### 2. Власний проєкт («Фабрика соків» / Juice Factory Store):
* **Модульні тести (3 модулі)**:
  * `src/discount.js` (`tests/discount.test.js`) — розрахунок диференційованих знижок (VIP 15%, опт 25%, чек від 1000 грн 5%, захист від від'ємних значень).
  * `src/validator.js` (`tests/validator.test.js`) — комплексна валідація замовлення (ім'я, валідність email регулярним виразом, позитивна кількість).
  * `src/inventory.js` (`tests/inventory.test.js`) — верифікація залишків продукції на складі та виявлення дефіциту.
* **Інтеграційні тести (2 сценарії)**:
  * `src/orderService.js` (`tests/orderPipeline.test.js`) — наскрізний ланцюжок: валідація → перевірка наявності → розрахунок знижки → списання залишків зі складу, а також транзакційне блокування при нестачі.
  * `src/paymentService.js` (`tests/paymentApi.test.js`) — інтеграція із зовнішнім банківським API (`https://api.payments-bank.com/v1/charge`) через мокування запитів `axios.post`.
